# Folio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Folio, a standalone Windows Electron reading companion that captures book pages, OCRs them, lets you highlight words on the screenshot, and rolls notes into a per-book Summary.

**Architecture:** Electron main process owns all disk access (`library.js`), screen capture (`capture.js`) and OCR (`ocr.js` → `ocr.ps1`). A single frameless window runs a vanilla-JS router with three views (library, book, summary). Pure helpers (`shared/names.js`, `shared/words.js`, `main/summary.js`) are unit-tested with `node --test`.

**Tech Stack:** Electron ^33.2.0, plain CommonJS JavaScript, Node built-in test runner, Windows PowerShell 5.1 + `Windows.Media.Ocr`.

Spec: `docs/superpowers/specs/2026-09-13-folio-reading-companion-design.md`

## Global Constraints

- Windows 11 only; single user.
- No AI features, no network access.
- `contextIsolation: true`, `nodeIntegration: false`; renderer talks only through `window.folio` (preload).
- Design tokens copied verbatim from Tick `src/renderer/shared/theme.css`.
- Library root default `Documents\Folio`; settings at `%APPDATA%\Folio\settings.json`.
- Book folder = sanitized title; chapter folder = `NN Title`; page = `NNN.png` + `NNN.json`.
- Default hotkey `Control+Alt+B`.
- Atomic JSON writes (tmp + rename), strip UTF-8 BOM on read.
- Only dependencies: `electron`, `electron-builder` (dev).

### Task 1: Scaffold + names helpers

**Files:** Create `package.json`, `src/shared/names.js`, `test/names.test.js`

**Produces:** the `names.js` functions listed in the file map.

- [ ] Write `test/names.test.js`:

```js
const test = require('node:test');
const assert = require('node:assert');
const n = require('../src/shared/names');

test('sanitizeName strips illegal chars, trims, caps length', () => {
  assert.strictEqual(n.sanitizeName('  Atomic: Habits? <v2>  '), 'Atomic Habits v2');
  assert.strictEqual(n.sanitizeName('a'.repeat(120)).length, 80);
  assert.strictEqual(n.sanitizeName('...'), 'Untitled');
  assert.strictEqual(n.sanitizeName('CON'), 'CON_');
});
test('chapter dir names round-trip', () => {
  assert.strictEqual(n.chapterDirName(3, 'The Plan'), '03 The Plan');
  assert.deepStrictEqual(n.parseChapterDir('03 The Plan'), { index: 3, title: 'The Plan' });
  assert.strictEqual(n.parseChapterDir('notes'), null);
});
test('page files', () => {
  assert.strictEqual(n.pageBase(7), '007');
  assert.strictEqual(n.parsePageFile('007.json'), 7);
  assert.strictEqual(n.parsePageFile('007.png'), null);
});
test('uniqueName adds (2), (3)', () => {
  assert.strictEqual(n.uniqueName('Book', new Set(['book', 'book (2)'])), 'Book (3)');
});
```

- [ ] Run `npm test` → FAIL (module missing). Implement `names.js`. Run → PASS. Commit.

- `deletePage(id, pageId)` (renumbers)
- `pagePath(id, pageId) -> absolute png path`
